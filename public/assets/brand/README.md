Put the brand logo here as `scan-logo.png` (transparent PNG, roughly 2:1).

When the file exists the game shows it on the back of the runner's cap and on the
loading / menu screens. Without it the cap is plain. The logo is not included in the
repository; only add it if you have the rights to use it.

On the CloudPanel server, upload it to `htdocs/<domain>/shared/brand/scan-logo.png` instead
(see DEPLOYMENT.md); each deploy copies it into place.
